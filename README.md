Organization-level GitHub configuration for [Rethunk-Tech](https://github.com/Rethunk-Tech). Houses the public org profile README, shared workflow templates, and CI lint for workflow files in this repository.

## Quick start

```bash
git clone https://github.com/Rethunk-Tech/.github.git
```

This org-templates dossier has no HUMANS-tier runbook — edit `profile/README.md` for the landing page and `.github/workflows/` for reusable automation.

## Highlights

- Org profile README with pinned repositories
- Shared GitHub Actions workflow definitions
- CI validates workflow YAML on push via actionlint
